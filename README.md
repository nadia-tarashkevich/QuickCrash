# QuickCrash

<!-- Plugin description -->
A minimal IntelliJ Platform plugin that provides a single action: it shows a "Hello world" dialog.

Use it via Tools > Hello World.
<!-- Plugin description end -->

## Usage
- In the IDE, open the Tools menu and click "Hello World". A dialog with the text "Hello world" will appear.

## Installation
- From disk: Settings/Preferences > Plugins > ⚙️ > Install plugin from disk... (select the built ZIP from Releases or your local build)

---
Plugin based on the IntelliJ Platform Plugin Template.
